```zsh
_td_storage_init()            # Ensure data dirs exist
_td_storage_modify()          # Args: <file> <js_transform> → atomically modifies JSON
_td_storage_list_path()       # Args: [list_name] → prints tasks.json path
```

Key concern from research (Pitfall 1): _td_storage_modify sets JSON_DATA internally.
Extra env vars (TASK_ID, NEW_TEXT) must be exported before calling _td_storage_modify
so they are visible to the osascript child process via $.NSProcessInfo.
Pattern: `export TASK_ID="$val"; _td_storage_modify ...; unset TASK_ID`

  <behavior>
    - todo edit ABC123 "New title" updates task text and prints confirmation
    - todo edit (no args) prints usage error, returns 1
    - todo edit ABC123 (no new title) prints "New title required" error, returns 1
    - todo edit ZZZZZZ "text" prints "No task matching" error, returns 1
    - todo rm ABC123 removes task from storage, prints confirmation
    - todo rm (no args) prints usage error, returns 1
    - todo rm ZZZZZZ prints "No task matching" error, returns 1
  </behavior>
  <action>
1. Create `commands/td-edit` (no .zsh extension, no function wrapper):
   - Parse args: `local id_prefix="$1"`, then `shift 2>/dev/null`, `local new_text="$*"`
   - Validate id_prefix non-empty: `_td_error "Usage: todo edit <task-id> <new title>"` + return 1
   - Validate new_text non-empty: `_td_error "New title required"` + return 1
   - `_td_storage_init`
   - Get tasks_file from `_td_storage_list_path`
   - Resolve full ID: `task_id="$(_td_resolve_task_id "$tasks_file" "$id_prefix")" || return 1`
   - **Export env vars before modify call** (research Pitfall 1):
     ```
     export TASK_ID="$task_id"
     export NEW_TEXT="$new_text"
     ```
   - Call `_td_storage_modify "$tasks_file"` with JXA transform:
     - Read TASK_ID and NEW_TEXT from `$.NSProcessInfo.processInfo.environment`
     - `var idx = data.tasks.findIndex(function(t) { return t.id === tid; });`
     - `if (idx === -1) throw new Error("not found");`
     - `data.tasks[idx].text = txt;`
     - `data.tasks[idx].updated = new Date().toISOString();`
   - Capture return code, unset TASK_ID and NEW_TEXT
   - On success: `_td_success "Updated task ${task_id:0:8}"`
   - See 03-RESEARCH.md Code Examples td-edit for reference

2. Create `commands/td-rm` (no .zsh extension, no function wrapper):
   - Parse args: `local id_prefix="$1"`
   - Validate non-empty: `_td_error "Usage: todo rm <task-id>"` + return 1
   - `_td_storage_init`
   - Get tasks_file, resolve full ID via `_td_resolve_task_id`
   - **Export TASK_ID** before modify call
   - Call `_td_storage_modify "$tasks_file"` with JXA transform:
     - Read TASK_ID from environment
     - `data.tasks = data.tasks.filter(function(t) { return t.id !== tid; });`
   - Unset TASK_ID
   - On success: `_td_success "Removed task ${task_id:0:8}"`
   - See 03-RESEARCH.md Code Examples td-rm for reference
  </action>
