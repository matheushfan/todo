Create commands/td-bulk:

**Subcommand dispatch:**
```
local subcmd="$1"; shift 2>/dev/null
case "$subcmd" in
  done) _td_bulk_done "$@" ;;
  move) _td_bulk_move "$@" ;;
  rm)   _td_bulk_rm "$@" ;;
  *)    _td_error "Usage: todo bulk <done|move|rm> [--all|--status <s>] <ids...>" ; return 1 ;;
esac
```

**ID collection helper _td_bulk_collect_ids:**
1. Accept tasks_file and remaining args
2. Parse flags with zparseopts: `--all` and `--status:`
3. If --all: use JXA to get all task IDs from tasks_file, return comma-separated
4. If --status <s>: use JXA to get IDs of tasks matching that status, return comma-separated
5. Otherwise: iterate positional args, resolve each via `_td_resolve_task_id`. If ANY fails, abort immediately (return 1). Collect resolved full UUIDs.
6. If no IDs collected: error "No tasks specified" and return 1
7. Return comma-separated IDs to stdout

**_td_bulk_done:**
1. Call _td_bulk_collect_ids to get comma-separated IDs
2. Export TASK_IDS="$ids_csv"
3. Single _td_storage_modify call with JXA:
   ```javascript
   var ids = env.objectForKey("TASK_IDS").js.split(",");
   var doneStatus = data.statuses[data.statuses.length - 1];
   var count = 0;
   ids.forEach(function(tid) {
     var idx = data.tasks.findIndex(function(t) { return t.id === tid; });
     if (idx >= 0) { data.tasks[idx].status = doneStatus; data.tasks[idx].updated = new Date().toISOString(); count++; }
   });
   ```
4. Report: "Completed N task(s)"

**_td_bulk_move:**
1. First arg is target status, rest are IDs/flags
2. Validate target status exists (same pattern as td-move: read statuses, check in JXA)
3. Call _td_bulk_collect_ids for remaining args
4. Export TASK_IDS + NEW_STATUS
5. Single _td_storage_modify call setting status + updated timestamp
6. Report: "Moved N task(s) to '<status>'"

**_td_bulk_rm:**
1. Call _td_bulk_collect_ids
2. Export TASK_IDS
3. Single _td_storage_modify call filtering out matching IDs:
   ```javascript
   var ids = env.objectForKey("TASK_IDS").js.split(",");
   var before = data.tasks.length;
   data.tasks = data.tasks.filter(function(t) { return ids.indexOf(t.id) === -1; });
   ```
4. Report: "Removed N task(s)"

**CRITICAL:** All helper functions (_td_bulk_done, _td_bulk_move, _td_bulk_rm, _td_bulk_collect_ids) must be defined INSIDE the td-bulk file body since autoload makes the file body the function body. Use nested function definitions.
