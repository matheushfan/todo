Create lib/_td_board with these functions:

**_td_board_render** (main entry point):
1. Accept tasks_file as $1
2. Get terminal width: `local term_width=${COLUMNS:-$(tput cols 2>/dev/null || echo 80)}`
3. Read statuses from tasks.json via single JXA call that returns newline-separated status names
4. Parse into zsh array: `local -a statuses=("${(@f)statuses_lines}")`
5. Calculate: `local col_width=$(( (term_width - num_cols - 1) / num_cols ))`
6. If col_width < 20 OR not a TTY `[[ ! -t 1 ]]`: call `_td_board_stacked` and return
7. Single JXA call to group ALL tasks by status. Return format: blocks separated by `__COL_SEP__`, tasks within block are newline-separated, fields tab-separated: `id\tpriority\ttags\ttext`
8. Parse grouped output into parallel arrays (one per column)
9. Find max_rows across all columns
10. Render header row: each status name UPPERCASE, bold cyan, centered in col_width, separated by `|`
11. Render separator row: `=` repeated col_width times per column, separated by `+`
12. Render task rows: for each row index 0..max_rows-1, print one cell per column using `_td_board_format_card`, separated by `|`
13. Empty cells: just spaces padded to col_width

**_td_board_format_card** (format single task cell):
1. Accept: id, priority, tags, text, width
2. Priority indicator: alta=`!`, media=`~`, baixa=`.` (colored via TD_PRIORITY_COLORS)
3. Short ID: first 8 chars, dim
4. Truncate text BEFORE colorizing: max_text = width - 12 (prefix) - 1 (padding). If text longer, truncate and append `~`
5. Build cell string with colors, return via printf

**_td_board_stacked** (fallback):
1. Accept tasks_file as $1
2. For each status: print bold cyan header, print `---` separator, print tasks (same format as td-ls but grouped)
3. Empty statuses: print "(empty)" in dim

- Test truncation: create task with very long title, set narrow COLUMNS, verify `~` truncation marker
