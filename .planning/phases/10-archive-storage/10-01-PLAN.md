**2. Create `commands/td-archive` with three subcommands:**

Follow the subcommand dispatch pattern from td-list. The file needs:

**`_archive_do` (default, no args) — DATA-03:**
- `_td_storage_init`, get `tasks_file` and `archive_file` paths
- Determine the "done" status: read statuses array, last element is the done equivalent (same logic as td-done: `data.statuses[data.statuses.length - 1]`)
- Use a SINGLE JXA call that reads tasks.json, filters tasks with status === done_status, returns the count and a JSON array of matching tasks. If count is 0, print "No completed tasks to archive" and return 0.
- **Append-first-then-remove pattern** (two separate atomic operations):
  - Step A: Read archive.json (or create `{"name":"LIST_NAME","tasks":[]}` if it doesn't exist). Append the matched tasks to archive's tasks array, adding `archived_at: new Date().toISOString()` to each. Write archive.json atomically via `_td_storage_atomic_write`.
  - Step B: Remove the archived tasks from tasks.json via `_td_storage_modify` filtering out tasks whose status matches done_status.
- Print success: "Archived N task(s)"

For Step A, use env vars to pass the tasks JSON array and list name:
```zsh
# Read done tasks from active file via JXA
local done_tasks
done_tasks=$(JSON_DATA="$(cat "$tasks_file")" osascript -l JavaScript -e '
  function run() {
    var env = $.NSProcessInfo.processInfo.environment;
    var data = JSON.parse(env.objectForKey("JSON_DATA").js);
    var doneStatus = data.statuses[data.statuses.length - 1];
    var matched = data.tasks.filter(function(t) { return t.status === doneStatus; });
    if (matched.length === 0) return "__NONE__";
    return JSON.stringify(matched);
  }
' 2>/dev/null)

[[ "$done_tasks" == "__NONE__" || -z "$done_tasks" ]] && {
  _td_success "No completed tasks to archive"
  return 0
}
```

For the archive write (Step A):
```zsh
local archive_file
archive_file="$(_td_storage_archive_path)"
local list_name
list_name="$(_td_storage_active_list)"

local new_archive
new_archive=$(DONE_TASKS="$done_tasks" LIST_NAME="$list_name" EXISTING="$(cat "$archive_file" 2>/dev/null || echo '')" osascript -l JavaScript -e '
  function run() {
    var env = $.NSProcessInfo.processInfo.environment;
    var existRaw = env.objectForKey("EXISTING").js;
    var listName = env.objectForKey("LIST_NAME").js;
    var archive;
    if (existRaw && existRaw.length > 2) {
      archive = JSON.parse(existRaw);
    } else {
      archive = {name: listName, tasks: []};
    }
    var incoming = JSON.parse(env.objectForKey("DONE_TASKS").js);
    var now = new Date().toISOString();
    incoming.forEach(function(t) { t.archived_at = now; });
    archive.tasks = archive.tasks.concat(incoming);
    return JSON.stringify(archive, null, 2);
  }
' 2>/dev/null) || { _td_error "Failed to build archive"; return 1; }

_td_storage_atomic_write "$archive_file" "$new_archive" || {
  _td_error "Failed to write archive"
  return 1
}
```

For removing from active (Step B):
```zsh
_td_storage_modify "$tasks_file" '
  var doneStatus = data.statuses[data.statuses.length - 1];
  data.tasks = data.tasks.filter(function(t) { return t.status !== doneStatus; });
'
```

**`_archive_undo <id>` — restores task from archive to active:**
- Validate id_prefix argument
- `_td_storage_init`, get both file paths
- Resolve task ID from archive.json (use `_td_resolve_task_id` but pass archive_file). If archive.json doesn't exist, error "No archive found".
- **Append-first-then-remove** (reverse direction):
  - Step A: Read the matched task from archive via JXA (get full task object, remove `archived_at` field). Add it to tasks.json via a JXA call that reads tasks.json, pushes the task, writes back. Use `_td_storage_modify` on tasks_file with env var passing the task JSON.
  - Step B: Remove from archive.json via `_td_storage_modify` filtering out the restored task by ID.
- Print success: "Restored task SHORTID to active list"
