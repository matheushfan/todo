Add checkbox mode to `_td_interactive` (requirement UX-05):

**A. Add checkbox mode global** at top with other globals:
```zsh
typeset -g _TD_UI_CHECKBOX_MODE=0
```

**B. Update `commands/td-ui`** to parse --checkbox flag and pass to engine:
```zsh
# td-ui - interactive board view (zcurses)
local -a _td_ui_args=("$@")
local checkbox_flag=0
if [[ " ${_td_ui_args[*]} " == *" --checkbox "* ]]; then
  checkbox_flag=1
fi
_td_interactive_run $checkbox_flag
```

**C. Update `_td_interactive_run` entry point** to accept checkbox arg:
- Accept optional argument: `local force_checkbox="${1:-0}"`
- After `_td_interactive_load_data`, add auto-detection:
  ```zsh
  # Auto-detect checkbox mode: exactly 2 statuses, or forced via flag
  if (( force_checkbox )) || (( ${#_TD_UI_STATUSES[@]} == 2 )); then
    _TD_UI_CHECKBOX_MODE=1
  else
    _TD_UI_CHECKBOX_MODE=0
  fi
  ```

**D. Flatten data for checkbox mode**: In checkbox mode, navigation is a single flat list (no columns). Add a function `_td_interactive_flatten_for_checkbox`:
- Create a flat array `_TD_UI_CHECKBOX_ITEMS` (global, typeset -ga) containing all tasks across all statuses in order (unchecked first, then checked)
- Each entry is the same tab-separated format: `id\tpriority\ttags\ttext\tref\tstatus`  (add status as 6th field for checkbox)
- Set `_TD_UI_CHECKBOX_COUNT` (global) to total count
- Call this after `_td_interactive_load_data` when in checkbox mode

**E. Add checkbox navigation state**: In checkbox mode, use a single `_TD_UI_CHECKBOX_SEL=1` (1-indexed row in flat list). Add globals:
```zsh
typeset -g _TD_UI_CHECKBOX_SEL=1
typeset -g _TD_UI_CHECKBOX_COUNT=0
typeset -ga _TD_UI_CHECKBOX_ITEMS=()
```

**F. Create `_td_interactive_render_checkbox` function**:
- Use the FULL stdscr window (no column windows needed). Clear stdscr.
- Render header: list name centered, bold cyan (row 0)
- Render separator line (row 1): dashes
- For each task in `_TD_UI_CHECKBOX_ITEMS` starting at row 2:
  - Determine checked: if task's status == last status in `_TD_UI_STATUSES`, show `[x]`, else `[ ]`
  - Format: `[x] task text` or `[ ] task text`
  - If task is selected (`r == _TD_UI_CHECKBOX_SEL`): apply reverse video to entire row
  - Priority indicator before checkbox: `! [x] text`, `~ [ ] text`, `. [ ] text`, `  [ ] text`
  - Truncate text to fit terminal width: `COLUMNS - 8` chars max (priority + space + checkbox + space = 8)
  - Handle overflow: if more tasks than `LINES - 4`, show `... +N more` at bottom
- Render status bar at bottom (same pattern as kanban but different keys):
  ```zsh
  " ${_TD_UI_LIST_NAME} | ${_TD_UI_CHECKBOX_COUNT} tasks | j/k:move Space:toggle d:done x:del ?:help q:quit "
  ```
  Use `zcurses move stdscr $(( LINES - 1 )) 0` for status bar (no separate window needed — simpler for checkbox).

Actually, for consistency and resize handling, still use the statusbar window from `_td_interactive_create_windows`. But skip creating column windows. Add a conditional in `_td_interactive_create_windows`:

```zsh
if (( _TD_UI_CHECKBOX_MODE )); then
  # Only header + statusbar, no column windows
  zcurses addwin header 1 $COLUMNS 0 0
  _TD_UI_WINDOWS+=(header)
  zcurses addwin statusbar 1 $COLUMNS $(( LINES - 1 )) 0
  _TD_UI_WINDOWS+=(statusbar)
else
  # existing column window creation code
  ...
fi
```

For the checkbox list body, use stdscr directly (rows 1 to LINES-2).

**G. Create `_td_interactive_action_toggle` function** (Space/Enter in checkbox mode):
- Get the selected task from `_TD_UI_CHECKBOX_ITEMS[$_TD_UI_CHECKBOX_SEL]`
- Parse its current status (6th tab field)
- If status == first status (unchecked): set to last status (checked)
- If status == last status (checked): set to first status (unchecked)
- Use `_td_storage_modify` with TASK_ID and NEW_STATUS env vars (same pattern as `_td_interactive_action_status`)
- Reload data: `_td_interactive_load_data` then `_td_interactive_flatten_for_checkbox`
- Clamp selection if needed

**H. Update input loop** with checkbox-mode branches:
```zsh
if (( _TD_UI_CHECKBOX_MODE )); then
  case $key$kkey in
    q) break ;;
    j|DOWN) (( _TD_UI_CHECKBOX_SEL++ )); (( _TD_UI_CHECKBOX_SEL > _TD_UI_CHECKBOX_COUNT )) && _TD_UI_CHECKBOX_SEL=1; _td_interactive_render_checkbox ;;
    k|UP) (( _TD_UI_CHECKBOX_SEL-- )); (( _TD_UI_CHECKBOX_SEL < 1 )) && _TD_UI_CHECKBOX_SEL=$_TD_UI_CHECKBOX_COUNT; _td_interactive_render_checkbox ;;
    ' '|$'\n') _td_interactive_action_toggle; _td_interactive_render_checkbox ;;
    d) _td_interactive_action_checkbox_done; _td_interactive_render_checkbox ;;
    x) _td_interactive_action_checkbox_delete; _td_interactive_render_checkbox ;;
    '?') if (( _TD_UI_HELP_VISIBLE )); then _td_interactive_hide_help; else _td_interactive_show_help; fi ;;
  esac
else
  # existing kanban case statement
  ...
fi
```
Note: h/l (column navigation) and s (status cycle) are not applicable in checkbox mode. Only j/k, Space/Enter (toggle), d (done=check), x (delete).

**I. Add checkbox-mode done and delete actions**: 
- `_td_interactive_action_checkbox_done`: Same as kanban done but works with `_TD_UI_CHECKBOX_ITEMS` and `_TD_UI_CHECKBOX_SEL`. Get task ID from selected checkbox item, set status to last status, reload + flatten, clamp selection.
- `_td_interactive_action_checkbox_delete`: Same pattern — get ID from checkbox item, delete via `_td_storage_modify`, reload + flatten, clamp selection.

**J. Update `_td_interactive_show_help`** to show different keybindings when in checkbox mode:
- When `_TD_UI_CHECKBOX_MODE == 1`, display:
  ```
  Navigation
    j / Down     Move down
    k / Up       Move up

  Actions
    Space/Enter  Toggle checkbox
    d            Mark done (check)
    x            Delete task

  General
    ?            Toggle this help
    q            Quit
  ```

**K. Update `_td_interactive_handle_resize`**: When in checkbox mode, call `_td_interactive_render_checkbox` instead of `_td_interactive_render`. Also clamp `_TD_UI_CHECKBOX_SEL` if it exceeds visible rows.

**L. Update `_td_interactive_init_selection`**: When in checkbox mode, set `_TD_UI_CHECKBOX_SEL=1` (first item in flat list).

**M. Update `_td_help` (lib/_td_help)**: Add `--checkbox` to the `td ui` line in the help text:
```
  ui [--checkbox]            Interactive board view (zcurses)
```
